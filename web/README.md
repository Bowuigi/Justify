# Web editor

Provides an experimental web editor and Preact components for various parts of each format.

## Getting Started

This webapp uses Typescript, Preact and Vite

-   `deno run dev` - Starts a dev server at http://localhost:5173/

-   `deno run build` - Builds for production, emitting to `dist/`

-   `deno run preview` - Starts a server at http://localhost:4173/ to test production build locally
